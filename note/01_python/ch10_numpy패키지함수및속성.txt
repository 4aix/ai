Numpy 패키지의 함수와 속성
- 배열 속성
	dtype : 요소들의 타입(타입변경시 astype(타입)이용)
	itemsize : 요소의 byte사이즈
	ndim : 차원수(축수)
	size : 요소 갯수
	shape : 배열의 구조 (tup)

- 배열 생성 함수
	np.array(obj, dtype, copy=T/F)
	np.array(obj, dtype, copy=T/F).reshape(행수,열수)
	np.zeros(tup, dtype)
	np.ones(tup, dtype)
	np.full(tup, 초기값, dtype)
	np.empty( tup, dtype )

	np.random.random( tup ) : 0부터 1미만의 균등분포를 갖은 tup 사이즈 n차원 배열
	np.random.uniform(low=0, high=1.0, size=tup) : low~high미만까지 균등분포 n차원 배열
	np.random.normal(loc=0.0, scale=1.0, size=tup) : 평균loc, 표준편차scale을 갖는 정규분포 n차원 배열
	np.random.rand(n) : 균등분포의 1차원 0~1미만 난수 1차원 배열(난수n개)
	np.random.randn(n) : 표준정규분포(평균0, 표준편차가1인 정규분포)의 1차원 배열(난수 n개)
	
	np.arange(from, to, by, dtype) : from~to앞까지 by씩 증감하는 1차원 배열
	np.linspace(from, to, num) : from~to까지 같은 간격의 num개 수를 1차원 배열

- 배열 차원 변경
	reshape() : -1 사용하면 자동 계산
	resize() : -1 불가
	T, transpose() : 전치행렬
	flattern(), ravel() : 1차원 변경
