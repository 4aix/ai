※ 가상환경 만들기(llm)

(현재 존재하는 가상환경 목록 확인) conda env list
                                             conda info --envs
(가상환경 생성) conda create -n llm python=3.10
(생성한 가상환경으로 전환) conda activate llm
(pip 업그레이드) python -m pip install --upgrade pip
(llm환경에 jupyter 설치) conda install ipykernel
(jupyter 설치 확인) conda list jupyter

(llm가상환경을 Jupyter에서 선택가능한 커널로 등록)
python -m ipykernel install --user --name llm --display-name "llm(ipykernel)"

(가상환경 등록 확인) jupyter kernelspec list


-----------------------------------------------------
(jupyter 커널 목록삭제)
jupyter kernelspec remove "llm"
(llm 가상환경 삭제)
conda env remove --name llm
