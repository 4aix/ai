1. Oracle셋팅 후, cmd창을 띄워 다음을 실행
2. 관리자계정으로 접속
 c:\~>sqlplus system/설치시비번
 c:\~>sqlplus / as sysdba
         sqlplus "/as sysdba
3. scott 계정생성 및 권한부여(dba)
 SQL> create user scott identified by tiger;
 User created.
 SQL> grant dba to scott;
 Grant succeeded.
4. 관리자 계정 접속 해제
 SQL> exit;
5. scott계정으로 접속후, 수업시간에 쓸 데이터(demo.sql) 넣기
 c:\~>sqlplus scott/tiger
 SQL> @c:/ai/lecNote/04_DBMS/demo.sql;
 c:\~>
6. scott계정으로 접속후, 데이터 확인
 c:\~>sqlplus scott/tiger
 SQL> SELECT * FROM TAB; -- 테이블들
 SQL> SELECT * FROM EMP; -- DEPT테이블 정보(여기선 안 되겠네)
 SQL> EXIT
